# Milaan 2026 PWA

## Publiceren via GitHub Pages
1. Maak op GitHub een nieuwe repository, bijvoorbeeld `milaan-2026`.
2. Upload alle bestanden uit deze map, waarbij `index.html` in de hoofdmap staat.
3. Open in de repository: Settings > Pages.
4. Kies bij Build and deployment: Deploy from a branch.
5. Kies branch `main`, map `/ (root)` en klik Save.
6. Open na publicatie de door GitHub getoonde website op de telefoon.

## Installeren op iPhone
Open de site in Safari, tik op Delen, kies Zet op beginscherm / Add to Home Screen, kies indien getoond Open as Web App en tik Voeg toe.

## Installeren op Android
Open de site in Chrome, open het menu en kies Installeren of Toevoegen aan startscherm.

## Lokaal testen
Start in deze map een lokale server, bijvoorbeeld `python3 -m http.server 8000`, en open `http://localhost:8000`.

Let op: installatie en service worker vereisen HTTPS of localhost. Kaarttegels en actuele Google Maps-routes vereisen internet.
